# Scoring Changes Made

This file records only the changes made during the scoring-analysis task. No rollback was executed after the request to revert: the request was interrupted before any files were restored.

## Business Logic Applied

- Final-evaluation score is calculated from objective weights and the Team Leader's confirmed achievement percentage.
- Per objective contribution: `weight * managerConfirmedAchievement / 100`.
- Final score is the sum of those contributions when the eligible objective weights total 100.
- For incomplete legacy objective-weight totals, the existing service normalizes the weighted result back to 0-100.
- Employee self-assessment remains visible evidence. It is used only as a fallback in the service until a Team Leader confirms an achievement percentage.
- The ML service's `overall_score`, predicted rating, and promotion probability remain separate from the persisted HR final-evaluation score.

## Final Evaluation Rating Bands Added

| Score | Rating label |
| --- | --- |
| 0 to 59.99 | `needs_improvement` |
| 60 to 74.99 | `meets_expectations` |
| 75 to 89.99 | `exceeds_expectations` |
| 90 to 100 | `exceptional` |

- Exported `FINAL_EVALUATION_RATING_BANDS`.

### `backend/models/FinalEvaluation.js`

- Changed `rating_label` enum to the four documented labels.
- Updated the `manager_score` comment to indicate legacy retention.

### `backend/controllers/finalEvaluationController.js`

- Removed the global score-override path for `manager_score` and `manager_adjustment_justification` in `updateEvaluation()`.
- Made `applyEvaluationSnapshot()` persist `auto_score`, `manager_score`, and `final_score` from the same objective-weighted calculation, with `score_difference = 0`.
- Recalculated the objective snapshot before saving a final evaluation.
- Removed score-adjustment warnings and adjustment-specific audit fields.
- Changed PDF wording from a manager override score to a manager-confirmed weighted score.

### `backend/controllers/evaluationController.js`

- Changed the generic evaluation rubric to the four final-evaluation bands.
- Used manager-confirmed achievement when building an objective assessment.
